# kuaishou-ops

快手运营自动化：**刷视频 / 读评论 / 回评论 / 点赞 / 出片 / 发视频 / 排程运营**，外加一个能自己开播的**直播台**。
既是命令行工具，也能作为 **MCP server** 挂进 DeepSeek Harness（模型侧直接拿到 `ks_*` 工具）。

> 这个项目是**给 AI 当操作手**用的：它自己刷、自己看、自己回、自己出片。片子是 AI 做的，账号也是 AI 在运营。
> 用之前请自己确认平台规则和账号风险。

## 它现在能做什么

| 能力 | 说明 |
|---|---|
| 刷视频 | 不限量（按时间预算跑），顺手学网络梗、记录点赞/评论数 |
| 点赞 | 真点，点赞数会回读确认，避免重复点 |
| 回评论 | 别人的 + 自己的作品下的；按标签白名单/黑名单筛，一个账号回一次够 |
| 发评论 | 在自己的视频下发一条（不是回复），发完回读确认 |
| 出片 | 模板卡片风 + Vibe 知识大赏风 + 竖屏归一化/字幕/配音/BGM/封面 |
| 发视频 | 创作者服务平台，带话题/封面/防重复发布 |
| 全自动 | 刷 → 赞 → 回 → 出片 → 发布，任一步失败自动跳过并说明原因 |
| **直播台** | 读直播间弹幕 → 合成直播画面（游戏画面 + 角色气疱回弹幕 + 余额/计时胶囊）→ 本地录制或推流 |

## 两种后端，同一套工具

`config.json` 的 `mode`，默认 `auto`：

| 后端 | 驱动对象 | 需要什么 | 游客能做什么 | 登录后能做什么 |
|---|---|---|---|---|
| `web` | **快手网页版**（真实 Edge，持久化 profile） | 本机 Edge | 刷、读评论 | 赞、回复、发布（创作者服务平台） |
| `adb` | MuMu 模拟器 / 真机上的快手 App | MuMu + adb + ADBKeyboard | 刷、读评论 | 赞、回复、发布 |

`auto`：找到 adb 且有在线设备 → `adb`；否则 → `web`。日常用 `web` 就行，不用装模拟器。

## 装进 DSH

```bash
cd kuaishou-ops
npm install
node install.mjs --profile desktop      # 或 --profile web
# 重启 DSH（或让它重载 profile）
```

装完得到两处入口：

| 位置 | 内容 |
|---|---|
| **设置 → kuaishou** | 后端、配额、人设与说话方式、视频模板、配音、直播参数，共 **99 项**，改完即时生效 |
| 对话里的工具 | **58 个 `ks_*` 工具** |

值的合并顺序（后者覆盖前者）：`config.json` → `state/settings.json` → profile `cordis.patch.yml` 的 user 层。

## 直播台是怎么工作的

三件事拼起来：

1. **读弹幕**：登录态下打开直播间页面，按多组选择器取弹幕文本，解析成 `{谁, 说了什么}`，同一人刷屏去重。
2. **画面**：一个 1080×1920 的合成页（`state/live/stage.html`），游戏本体铺底，四枚胶囊（AI 在玩 / 计时 / 弹幕数 / 余额）配色跟游戏一致，右下角角色头顶气泡回弹幕。
3. **玩**：读取游戏内部状态（只读接口，不改游戏逻辑）→ 需要跳多远 → 按住对应时长松手；敌人逼近就用道具反击。

直播画面有三种输出方式：

| 方式 | 说明 |
|---|---|
| 本地录制 | `ks_live_play` 直接出 mp4（画面 + 游戏音效 + 语音） |
| 窗口采集 | `node tools/live-window.mjs` 开一个画面窗口，快手直播伴侣「窗口采集」选它即可开播 |
| rtmp 推流 | `ks_live_push` 需要你从开播页拿到 rtmp 地址与串流密钥 |

> 说明：**快手网页端不提供开播入口**（创作者后台的「去直播」跳转的是直播伴侣下载页）。所以要么用直播伴侣采窗口，要么自己拿 rtmp 地址推流。

## 视频风格

| 风格 | 工具 | 长什么样 |
|---|---|---|
| 模板卡片 | `ks_video_from_text` | 背景（渐变/图/视频）+ 标题 + 逐句字幕 + 配音 |
| 知识视频 | `ks_kv_video` | 一屏一句、卡点、大字排版（参考 Win-Hao/knowledge-video 的做法） |
| 素材拼接 | `ks_video_compose` | 用你自己录的片段/图片拼 |

配音默认走 **Piper 华颜**（免费开源、纯本地）＋ `cute loli` 预设 ＋ 柔化；没装 Piper 会自动退回系统语音。换声音在设置页，带「▶ 试听」。

## 稳定性相关的几个实现细节

这些都是踩过坑之后加的，列出来是因为它们决定了这个项目能不能长时间无人值守地跑：

- **单一所有者**：只有 MCP 进程能持有浏览器 profile 锁。外部脚本抢锁会把浏览器搞崩（实测杀过 12 个 Edge 进程）。
- **防重复发布**：同文件大小 + 同文案在 12 小时内只发一次（曾经同一个视频连发 4 次）。
- **停止标记**：点停止后，逐个动作工具都会检查，不会"停了还在回评论"。
- **页面失效自愈**：登录态过期、页面变 `about:blank` 时给明确的修复指引，而不是超时。
- **所有失败都如实报告**：拿不到余额就说拿不到，没推流地址就说没地址，不假装成功。

## 开发

```bash
npm test          # 463 个用例
npm run doctor    # 环境自检
npm run smoke     # MCP 工具注册冒烟
npm run validate  # 设置项 schema / 客户端 / 配置三方对齐检查
node tools/release-check.mjs   # 发布前体检：按 .gitignore 算出真正会进仓库的文件，扫私密信息与超大文件
```

目录：

```
src/         核心（web 驱动、mcp 工具、视频、配音、直播、去 AI 味…）
test/        测试（含 MCP 冒烟、e2e 脚本）
plugins/     DSH 插件本体（设置页 + 面板按钮）
prompts/     提示词（人设、回评、口播、改写…）
skills/      随项目带的技能（knowledge-video）
tools/       构建、发布、自检脚本
```

## 配置

复制 `config.example.json` 为 `config.json` 再改。**`config.json`、`state/`、`.web-profile/` 都已 gitignore**——里面有登录态和聊天记录，不要提交。
