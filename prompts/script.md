# 口播脚本

主题：{{topic}}
账号人设：{{personaSummary}}
目标时长：约 {{durationSec}} 秒（中文口播约 4.5 字/秒，所以总字数 ≈ {{targetChars}} 字）
平台：{{platform}}

## 结构（必须遵守）

1. **钩子（前 3 秒）**：一句反常识 / 一个具体场景 / 一个数字。不要「大家好」。
2. **具体过程**：讲一件真事，有时间、有细节、有数字。不泛泛而谈。
3. **转折**：遇到的坑、误判、或者意外发现。
4. **落点**：一句可带走的结论，或者一个反问。

## 硬规则

- 全文口语，能念出来不别扭；每句 ≤ 25 字
- 不用「赋能」「闭环」「干货」这类词
- 不编造数据、不冒充他人经历、不承诺收益
- 不出现品牌导流、联系方式
- 结尾不加「点赞关注」

## 输出格式

只输出 JSON：

```json
{
  "title": "12 字以内的大标题",
  "lines": ["逐句字幕，一句一行，共 4~8 句"],
  "voiceText": "把 lines 连起来、可直接 TTS 念的整段（不要加标点以外的标记）"
}
```
